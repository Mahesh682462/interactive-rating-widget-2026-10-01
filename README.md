# Interactive Rating Widget

A small, interactive 1-5 star rating component that allows users to select a rating and submit it, displaying a "thank you" message with their chosen score.

## How to Run

1.  Clone this repository or download the files.
2.  Open `index.html` in your web browser.

## Features

*   Select a rating from 1 to 5 stars.
*   Visual feedback on hover and selection.
*   "Thank You" state displays the submitted rating.
